# Product

## Register

product

## Users

Developers configuring a Claude Code status line. They use the tool while tailoring a terminal workflow and need to assemble, preview, and export a status line without hand-authoring every data formatter.

## Product Purpose

Statusline Maker makes the available status data understandable and configurable, then produces ready-to-use Bash, Python, or Node.js output. Success is a status line that communicates the right information at a glance and can be installed with confidence.

## Brand Personality

Practical, calm, and terminal-native. The interface should feel precise and familiar to developers without competing with the status line being configured.

## Anti-references

Avoid decorative dashboard tropes, marketing-style visual excess, and ambiguous labels. Do not make compact operational information harder to scan for the sake of novelty.

## Design Principles

- Make every status value immediately interpretable.
- Keep configuration close to its visible result.
- Favor compact, familiar developer-tool patterns.
- Generate portable, copy-ready output.
- Reveal detail only when it improves a decision.

## Accessibility & Inclusion

Target WCAG AA contrast. Do not rely on color alone for meaning, and respect reduced-motion preferences for any future motion.
